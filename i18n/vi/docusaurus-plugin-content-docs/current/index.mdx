# EKS Workshop: chạy microservices trên hai EKS cluster

Trong workshop này, bạn từng bước xây dựng nền tảng Kubernetes trên Amazon EKS theo hướng vận hành thực tế, bằng Terraform và GitOps:

- **Cluster 1 — Workload**: Managed Node Group cho công cụ nền tảng, ba nhóm node Karpenter (Spot, mixed On-Demand/Spot 1:3, ARM64) và microservices ShopNow được ArgoCD triển khai, sử dụng EFS, phân bổ đều trên các node và được bảo vệ bằng PodDisruptionBudget.
- **Cluster 2 — Observability**: metrics tương thích Prometheus (Mimir), logs (Loki) và Grafana nhận dữ liệu chuyển từ cluster 1.

Mỗi bước kết thúc bằng phép kiểm tra có thể chạy trực tiếp, để cuối cùng bạn có nền tảng hoạt động **và** bằng chứng đáp ứng từng yêu cầu.
