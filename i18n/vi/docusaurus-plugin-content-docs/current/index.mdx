# EKS Workshop

Trong workshop này, chúng ta sẽ từng bước xây dựng nền tảng Kubernetes trên Amazon EKS theo hướng vận hành thực tế, bằng Terraform và GitOps:

- **Cluster 1 — Workload**: Managed Node Group cho các công cụ như ArgoCD, Karpenter và 3 Node Group Karpenter (Spot, mixed On-Demand/Spot 1:3, ARM64) và dự án Microservices ShopNow được triển khai với ArgoCD.
- **Cluster 2 — Observability**: Centralized Observability (Prometheus, Grafana, Loki,...) - Triển khai Collect Metrics, Logs từ Cluster Workload sang Cluster Observability.
