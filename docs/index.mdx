# EKS Workshop: run microservices on two EKS clusters

In this workshop you build a production-style Kubernetes platform on Amazon EKS, step by step, with Terraform and GitOps:

- **Cluster 1 — Workload**: a Managed Node Group for platform tools, three Karpenter node pools (Spot, mixed On-Demand/Spot 1:3, ARM64), and the ShopNow microservices deployed by ArgoCD on EFS storage, spread evenly across nodes and protected by PodDisruptionBudgets.
- **Cluster 2 — Observability**: Prometheus-compatible metrics (Mimir), logs (Loki) and Grafana that receive everything shipped from cluster 1.

Every step ends with a check you can run, so at the end you have a working platform **and** the evidence that each requirement is met.
